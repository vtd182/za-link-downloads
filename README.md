# ZA Link downloads

Public distribution of the ZA Link local Figma MCP runtime and companion Figma plugin.

**[Download the latest preview](https://github.com/vtd182/za-link-downloads/releases/tag/v0.2.0-internal.2)** · **[Website](https://vtd182.github.io/za-link/)** · **[Installation](INSTALL.md)**

## What is included

Choose a ZIP for macOS, Windows or Linux, on ARM64 or AMD64. Each kit includes the native runtime, Figma plugin, configuration helper, usage documentation and file checksums. Releases include `SHA256SUMS.txt` for archive verification.

The version retains its `internal` prerelease suffix to match the tested runtime and plugin. These downloads are publicly accessible previews.

This repository contains distribution documentation and release files only. The development repository and its history remain private. Internal skill exports, Android/ZDS or Zinstant project code, Claude bundles with internal skills, credentials and private demo material are not distributed here.

The public kit does not require a skill pack to expose its MCP tools. Project-specific guided workflows require separately authorized skills and libraries. AI client/model costs and Figma permissions still apply.

## Tiếng Việt

Đây là kho tải công khai cho runtime MCP local và plugin Figma của ZA Link. Chọn bộ cài đúng hệ điều hành/kiến trúc, rồi làm theo [hướng dẫn cài đặt](INSTALL.md). Không cần quyền truy cập repo phát triển để tải.

Source phát triển và skill nội bộ được giữ riêng. Bộ cài public không chứa skill ZDS/Zinstant hoặc source ứng dụng nội bộ.
